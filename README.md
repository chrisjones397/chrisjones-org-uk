# chrisjones.org.uk

The site is plain HTML, CSS and JavaScript: what is in this repository is exactly what is published.

## Branches

- **main** is the live site. Nothing is worked on here directly; it only receives finished work from dev.
- **dev** is where changes are made and checked. When a change is approved, dev is merged into main.
- **painted-forest-tools** holds the scripts, photo and brush stamps that make the opening video. It is not
  part of the site and is never published or merged.

Every commit is kept, so any file, or the whole site, can be returned to an earlier state.
